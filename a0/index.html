Three ways to use a model

You'll use all three in AI Gym. Products are built on the third.

1. For your own work

Chat apps

Claude, ChatGPT, Gemini. Great for research, drafts and thinking things through.

You can't control: the hidden instructions, the exact model version, or the settings.

2. For testing

Playgrounds

Google AI Studio, the OpenAI Playground, the Claude Console. You choose the model, write the system prompt and set temperature.

Use it to: try a prompt before anyone writes code.

3. For products

The API

Your code sends text to the model and gets an answer back, with a token count and a price on every call.

Every AI feature you ship runs this way, behind the scenes.

Lab: Your first API call, safely About 30 minutes

Get a free API key, call a model from code, price the call, and learn where the spend caps live before you ever use a paid key. Your ticks and notes stay in this browser.

Key takeaways

  1. Chat apps for your work, playgrounds for testing, the API for products. Only the API gives you the full control a product needs.
  2. An API key is a password with a bill attached. Keep it in a secrets store, never in code you share.
  3. Free tiers can trade your data for the price. Read what the provider does with your prompts before you send anything real.
  4. An alert isn't a cap. Set a hard spend limit before you use a paid key.
